# Java Live Transcription

Get started using Deepgram's Live Transcription with this Java demo app

## Quick Start

Click the button below to fork the repo:

[![Fork on GitHub](https://img.shields.io/badge/Fork_on_GitHub-blue?logo=github)](https://github.com/deepgram-starters/java-live-transcription/fork)

## Local Development

### Requirements

- JDK 21 or later. Verify with `java --version`.
- Maven 3.9 or later.
- Git.
- Node.js with Corepack enabled. Run `corepack enable` to provide pnpm for the frontend install.

### Makefile (Recommended)

```bash
make init
cp sample.env .env  # Add your DEEPGRAM_API_KEY
make start
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
